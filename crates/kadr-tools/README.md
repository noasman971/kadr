# kadr-tools

The editing tools Claude can call, each defined once: name, description for a
language model, JSON parameter schema, and execution into Kadr commands.

- **Will depend on:** `kadr-core`, `kadr-engine`.
- **Used by:** `kadr-mcp`.
- **Status:** empty skeleton (phase 0). Implemented in phase 5.

See [docs/decisions/0004-claude-through-local-mcp-only.md](../../docs/decisions/0004-claude-through-local-mcp-only.md).
