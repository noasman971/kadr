# kadr-core

The Kadr data model: project, timeline, tracks, clips, effects, keyframes, and the
undoable commands that change them.

- **Depends on:** nothing inside Kadr.
- **Used by:** every other crate.
- **Must never depend on:** video decoding, GPU, user interface or platform-specific code.
- **Status:** empty skeleton (phase 0). Implemented in phase 1.

See [docs/architecture.md](../../docs/architecture.md).
