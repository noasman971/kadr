# kadr-media

Media input and output: probing files, decoding video and audio with frame-accurate
seeking, encoding exports, and extracting thumbnails and waveforms.

- **Will depend on:** `kadr-core`.
- **Used by:** `kadr-engine`.
- **Backends:** FFmpeg on desktop (phase 2), Android `MediaCodec` (phase 9), behind
  the same traits.
- **Status:** empty skeleton (phase 0). Implemented in phase 2.

See [docs/architecture.md](../../docs/architecture.md).
